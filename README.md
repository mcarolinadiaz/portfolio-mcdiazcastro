This repository contents an SPA (Single Page Application) code was developed with Angular v22 to shows professional background, tested with Vitest and deployed with Vercel.

## Requeriments

To execute this project you must need:

- Node.js (24 version or higher)
- npm (11 version or higher)
- Angular CLI (22 version or higher)

## Installation

1. **Clone this repo:**
   ```

2. **Install dependencies**
    ```
    cd portfolio-front
    npm install
